# search-reply-splitter

轻量中文聊天消息切分与分段发送组件。角色中立，不包含角色卡或俏皮话生成器。

## 下载

- [完整源码包](natural-reply-splitter-0.1.0.zip)：源码、使用说明、示例、测试和相关项目对照。
- [精简使用包](natural-reply-splitter-0.1.0-lite.zip)：仅四个运行文件，放进自己的 Python 项目即可导入。
- [整合下载包](search-reply-splitter.zip)：同时包含上述两包、简要中文说明和校验值。
- [SHA256 校验值](SHA256SUMS.txt)。

完整包与精简包的运行模块一致，选择其中一个即可。当前仓库以 ZIP 分发，源码在完整包内。

## 功能

- 闲聊最多切成两条，优先明确段落和完整句末；逗号兜底可选，默认关闭。
- 默认保留原文标点和语气，不调用模型改写内容。
- 搜索正文与来源放在同一条消息；可接收宿主提供的前置、后置文本，但不会自动生成。
- 首条默认等待 1.8～2.2 秒，取得回执后，后续每条等待 0.8～1.2 秒。
- 支持取消等待；发送异常停止，不自动重发。

## 使用

Python 3.10+，第三方运行依赖为零。完整包解压后，在其根目录执行：

```sh
python examples/demo.py
python -m unittest discover -s tests -v
```

精简包解压后将 `natural_reply` 放入项目：

```python
from natural_reply import split_reply, Source, search_messages, send_in_order
parts = split_reply("今天的事情终于做完了！接下来可以好好休息一下", casual=True)
```

这是可接入的 Python 组件，不是完整聊天机器人。联网搜索、模型、平台发送接口、消息幂等与持久化恢复由宿主提供。过长搜索消息会报错，不会静默删减步骤。断句是启发式规则，不保证语义分析准确。
